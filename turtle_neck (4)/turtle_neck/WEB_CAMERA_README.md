# 웹 캠 연동 실행 방법

자세 측정 프로그램의 캠 영상과 측정 기록을 웹 한 화면에서 보여줍니다.
점수, 관절, 상태, 거울 표시가 포함된 영상을 전달합니다.

## 실행 위치

이 설명서는 `feature/p` 브랜치의 다음 폴더에 있는 웹 캠 연동 버전용입니다.

```text
turtle_neck (4)/turtle_neck/
```

기준 코드는 `feature/i`의 커밋 `16b28d36b08da012d363f2b7187e85bf83063d14`입니다.
저장소 최상위의 기존 프로그램과 실행 위치를 혼동하지 않도록 주의하세요.

## 실행 방법

라즈베리파이에서 두 터미널을 열고, 각각 위 폴더로 이동한 다음 기존 가상환경을 활성화합니다.

터미널 1에서 서버를 실행합니다.

```bash
python app.py
```

터미널 2에서 자세 측정을 실행합니다.

```bash
python posture.py
```

같은 라즈베리파이의 브라우저에서 다음 주소를 엽니다.

**http://127.0.0.1:5050**

Flask가 없다면 기존 가상환경에서 설치합니다.

```bash
python -m pip install flask
```

OpenCV, NumPy, MediaPipe는 기존 `posture.py` 실행 환경을 그대로 사용합니다.
Python 3.11을 권장하며, MediaPipe 설치 가능 여부는 라즈베리파이 OS와 CPU, 버전에 따라 달라집니다.

## 필요한 파일

| 파일 | 역할 |
| --- | --- |
| `app.py` | 측정값 저장과 웹 영상 제공 |
| `posture.py` | 카메라 촬영, 자세 분석, 화면 표시 |
| `video_stream.py` | 처리된 영상의 백그라운드 전송 |
| `config.json` | 서버 주소와 영상 설정 |
| `templates/index.html` | 영상과 측정 기록을 함께 표시 |
| `test_web_video.py` | 카메라 없이 수행하는 자동 검증 |

기존 코드를 교체할 때는 코드와 설정을 먼저 백업하세요.
기존 `posture_data.db`, `turtle_neck.db`, `baseline.json`은 유지하세요.

## 설정

`config.json`을 수정한 뒤 `posture.py`를 다시 실행하면 반영됩니다.

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `server_url` | `http://127.0.0.1:5050/api/record` | 같은 기기에서 실행하는 서버의 측정값 수신 주소 |
| `web_video` | `true` | 웹 영상 사용 |
| `video_fps` | `10` | 웹 전송 속도, 초당 1~30프레임 |
| `video_jpeg_quality` | `75` | JPEG 품질, 30~95 |
| `show_window` | `true` | 별도 캠 창 표시 |

웹 화면만 사용하려면 `"show_window": false`로 변경하세요.
별도 창이 없어도 웹 영상은 계속 표시됩니다.

- 별도 캠 창이 켜져 있으면 해당 창에서 `c`로 재학습하고 `q`로 종료합니다.
- 별도 창을 끈 경우에는 자세 측정 터미널에서 `Ctrl+C`로 종료합니다.
- 브라우저에서는 기존 `c`와 `q` 단축키가 작동하지 않습니다.
- 재학습이 필요하면 별도 캠 창을 켜서 `c`를 누르거나, 프로그램을 종료한 뒤 `baseline.json`을 백업하여 다른 위치로 옮기고 다시 실행하세요.

## 동작 방식

카메라는 `posture.py`만 엽니다.
점수와 관절 표시를 그린 프레임을 백그라운드에서 JPEG로 압축하여
로컬 `/api/video_frame`으로 전달합니다.

Flask는 최신 프레임 하나를 메모리에 보관하고,
브라우저에 `/video_feed`의 MJPEG 스트림으로 제공합니다.
영상 파일을 디스크나 DB에 저장하지 않습니다.

서버 연결이 끊기면 전송하지 못한 영상 프레임은 버리고 다시 연결합니다.
측정값은 기존 DB 재전송 기능으로 처리합니다.
3초 동안 새 영상이 없으면 웹에서 이전 영상을 숨기고 대기 상태를 표시합니다.

## 실행 시 참고

- Flask는 단일 프로세스로 실행하세요. 여러 worker는 영상 메모리를 공유하지 않습니다.
- `/api/status`는 기존 판별기의 상태 알림을 받아 404 오류를 방지합니다. 별도 하드웨어 제어 기능은 포함하지 않습니다.
- 라즈베리파이에서 영상이 느리면 `video_fps`와 `video_jpeg_quality`를 낮춰 보세요.

## 검증

```bash
python test_web_video.py
```

영상 전달, JPEG 스트림, 측정값 저장, 잘못된 영상 요청 거부 등을 검증합니다.
실제 카메라 동작과 라즈베리파이 성능은 대상 기기에서 별도로 확인해야 합니다.
